کنترل‌های امنیتی فقط ظاهری نیستند

بخش‌های حساس سامانه در Backend کنترل می‌شوند؛ از جمله نشست کاربر، دسترسی مدیر، محدودیت درخواست‌های OTP و عملیات حساس.

✓
Session و کنترل دسترسی سمت سرورصفحات مدیر فقط برای حساب دارای نقش manager و Session معتبر ارائه می‌شوند.
✓
CSRF و محدودسازی تلاش‌هادرخواست‌های حساس و تلاش‌های ورود/OTP در Backend کنترل می‌شوند.
✓
لینک موقت برای فایل‌های خصوصیدانلود فایل‌های Object Storage از مسیرهای کنترل‌شده و URLهای موقت انجام می‌شود.
✓
Trash با امکان بازیابیحذف معمولی فایل فوراً آن را نابود نمی‌کند و امکان بازیابی پیش از حذف دائمی وجود دارد.
